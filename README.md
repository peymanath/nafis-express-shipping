## 🚚 What is this plugin?

**Nafis Express Shipping** integrates your WooCommerce store with the Nafis Express logistics system.

> ✅ In version `1.0.0`, you can:
>
> - View a dedicated list of exited WooCommerce orders
> - See barcode tracking data
> - Use token-based API authentication to fetch real-time results
